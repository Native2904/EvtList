# EvtList

Журнал событий Windows в виде папок в Total Commander.
Плагин файловой системы (WFX), только чтение, 32 и 64 бит.

English: [README.md](README.md) · Deutsch: [LIESMICH.md](LIESMICH.md) · Українська: [README.uk.md](README.uk.md) · Dansk: [README.da.md](README.da.md)

## Зачем

«Просмотр событий» Windows хранит всё, но прячет ответы за техническими терминами.
EvtList исходит из вопросов, которые возникают на самом деле:
*Что пошло не так? Почему компьютер перезагрузился? Какая программа постоянно падает?*
Исходные данные при этом доступны — уровнем ниже, для тех, кому они нужны.

## Папки

| Папка | Содержимое |
|---|---|
| `_Справка.txt` | Краткая справка на языке Total Commander (F3) |
| Проблемы | Критические ошибки и ошибки из журналов «Приложение» и «Система» |
| Перезагрузки и сбои | Неожиданные перезагрузки, синие экраны, плановые выключения, запуск/завершение Windows |
| Сбои программ | Аварийно завершённые и зависшие программы с именем программы (например, `Сбой AkelPad.exe`) |
| Все журналы | Полные журналы: Программы (Приложение), Windows (Система), Входы в систему (Безопасность) |

Известные события показываются понятным текстом вместо имени источника,
например `Неожиданная перезагрузка (41)` вместо `Kernel-Power (41)`.
У каждой записи есть значок ошибки, предупреждения или сведений.

## Клавиши

| Клавиша | Действие |
|---|---|
| F3 | Прочитать событие: значение, сообщение, поля и подробности |
| Enter | Открыть оригинал в «Просмотре событий» Windows |
| Alt+Enter | Меню действий (также: правый щелчок > Свойства) |
| Ctrl+S | Быстрый фильтр по имени, источнику или коду события |

Меню действий: поиск в интернете, копирование для форума, копирование сообщения,
*Что происходило в это же время?* (все доступные журналы ±5 минут),
открыть в «Просмотре событий», настройки.

Пользовательские столбцы: Level, DateTime, Source, SourceFull, EventID, TaskCategory,
User, Computer, Log, Meaning.

## Настройки

Правый щелчок по *EvtList* в сетевом окружении > Свойства
или Alt+Enter на событии > Настройки.

- Период для каждой группы папок: 1 час, 24 часа, 7/30/90 дней, все
- Показ и скрытие папок
- Поисковая система: Google, DuckDuckGo, Bing, Startpage, Ecosia или своя.
  Для своей найдите в ней слово `evtlist` и вставьте адрес из браузера.
- Что входит в *Копирование для форума*, удалять ли личные данные, теги `[code]`
- Язык: как в Total Commander или выбранный (после перезапуска Total Commander)

Размер диалога можно менять; на маленьких экранах появляются полосы прокрутки.

Все настройки хранятся в `EvtList.ini` в папке плагина; файл создаётся при первом запуске.
Если папка плагина защищена от записи, файл хранится рядом с `wincmd.ini`.
Справочник (русский, английский, немецкий, украинский, датский): [notes/settings](notes/settings/index.ru.html).

## Конфиденциальность

EvtList только читает локальные журналы событий и ничего никуда не отправляет.
*Искать в интернете* открывает браузер только с именем источника и кодом события.
*Копирование для форума* по умолчанию удаляет: имя пользователя, имя ПК, личные SID
и пути профиля пользователя (`C:\Users\<USER>\…`).

## Установка

Откройте zip-архив в Total Commander и подтвердите установку.
При обновлении убедитесь, что `EvtList.lng` тоже заменён.
Если старая версия оставила набор столбцов, удалите раздел
`[CustomFields_EvtList]` в `wincmd.ini` (при закрытом Total Commander).

## Требования и ограничения

- Windows Vista или новее. Проверено в Windows 11 и Total Commander 11.58 (64 бит).
- Журнал *Входы в систему* (Безопасность) доступен только при запуске Total Commander от имени администратора.
- Сообщения событий Windows выдаёт на языке Windows, а не Total Commander.
  Некоторые источники Microsoft дают категории задач только на английском.
- Меню действий работает с событием под курсором, а не с выделением.
  Несколько событий можно скопировать как текстовые файлы клавишей F5.
- *Что происходило в это же время?* открывается в редакторе по умолчанию для `.txt`.

## Переводы

Английский, немецкий, русский, украинский, датский — в `EvtList.lng`.
Русский, украинский и датский тексты ещё не проверены носителями языка;
исправления приветствуются. Новый язык — это новый раздел в `EvtList.lng`,
названный по языковому файлу Total Commander (`WCMD_POL.LNG` → `[pol]`).

## Сборка

MinGW-w64, см. `build.bat`. Исходники: `evtlist.cpp` (WFX), `evtsource.cpp` (доступ к журналам),
`settings.cpp` (ini и диалог), `lang.cpp` (переводы).
