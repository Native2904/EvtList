# EvtList

Журнал подій Windows у вигляді папок у Total Commander.
Плагін файлової системи (WFX), лише читання, 32 і 64 біт.

## Навіщо

«Переглядач подій» Windows зберігає все, але ховає відповіді за технічними термінами.
EvtList виходить із запитань, які виникають насправді:
*Що пішло не так? Чому комп'ютер перезавантажився? Яка програма постійно падає?*
Вихідні дані при цьому доступні — рівнем нижче, для тих, кому вони потрібні.

## Папки

| Папка | Вміст |
|---|---|
| `_Довідка.txt` | Коротка довідка мовою Total Commander (F3) |
| Проблеми | Критичні помилки та помилки з журналів «Програма» і «Система» |
| Перезавантаження та збої | Неочікувані перезавантаження, сині екрани, планові вимкнення, запуск/завершення Windows |
| Збої програм | Аварійно завершені й завислі програми з іменем програми (наприклад, `Збій AkelPad.exe`) |
| Усі журнали | Повні журнали: Програми (Програма), Windows (Система), Входи в систему (Безпека) |

Відомі події показуються зрозумілим текстом замість імені джерела,
наприклад `Неочікуване перезавантаження (41)` замість `Kernel-Power (41)`.
Кожен запис має значок помилки, попередження або відомостей.

## Клавіші

| Клавіша | Дія |
|---|---|
| F3 | Прочитати подію: значення, повідомлення, поля й подробиці |
| Enter | Відкрити оригінал у «Переглядачі подій» Windows |
| Alt+Enter | Меню дій (також: правий клік > Властивості) |
| Ctrl+S | Швидкий фільтр за назвою, джерелом або кодом події |

Меню дій: пошук в інтернеті, копіювання для форуму, копіювання повідомлення,
*Що відбувалося в той самий час?* (усі доступні журнали ±5 хвилин),
відкриття в «Переглядачі подій», налаштування.

Користувацькі стовпці: Level, DateTime, Source, SourceFull, EventID, TaskCategory,
User, Computer, Log, Meaning.

## Налаштування

Правий клік на *EvtList* у мережевому оточенні > Властивості
або Alt+Enter на події > Налаштування.

- Період для кожної групи папок: 1 година, 24 години, 7/30/90 днів, усі
- Показ і приховування папок
- Пошукова система: Google, DuckDuckGo, Bing, Startpage, Ecosia або власна.
  Для власної знайдіть у ній слово `evtlist` і вставте адресу з браузера в поле.
- Що входить до *Копіювання для форуму*, чи видаляти особисті дані, теги `[code]`
- Мова: як у Total Commander або вибрана (після перезапуску Total Commander)

Розмір діалогу можна змінювати; на малих екранах з'являються смуги прокручування.

Усі налаштування зберігаються в `EvtList.ini` у папці плагіна; файл створюється під час першого запуску.
Якщо папка плагіна захищена від запису, файл зберігається поруч з `wincmd.ini`.
Довідник (українська, англійська, німецька, російська, данська): [notes/settings](notes/settings/index.uk.html).

## Конфіденційність

EvtList лише читає локальні журнали подій і нічого нікуди не надсилає.
*Шукати в інтернеті* відкриває браузер лише з іменем джерела та кодом події.
*Копіювання для форуму* типово видаляє: ім'я користувача, ім'я ПК, особисті SID
і шляхи профілю користувача (`C:\Users\<USER>\…`).

## Встановлення

Відкрийте zip-архів у Total Commander і підтвердьте встановлення.
Під час оновлення переконайтеся, що `EvtList.lng` теж замінено.
Якщо стара версія залишила набір стовпців, видаліть розділ
`[CustomFields_EvtList]` у `wincmd.ini` (при закритому Total Commander).

## Вимоги та обмеження

- Windows Vista або новіша. Перевірено у Windows 11 і Total Commander 11.58 (64 біт).
- Журнал *Входи в систему* (Безпека) доступний лише тоді, коли Total Commander запущено від імені адміністратора.
- Повідомлення подій Windows видає мовою Windows, а не Total Commander.
  Деякі джерела Microsoft мають категорії завдань лише англійською.
- Меню дій працює з подією під курсором, а не з виділенням.
  Кілька подій можна скопіювати як текстові файли клавішею F5.
- *Що відбувалося в той самий час?* відкривається в редакторі за замовчуванням для `.txt`.

## Переклади

Англійська, німецька, російська, українська, данська — у `EvtList.lng`.
Російський, український і данський тексти ще не перевірені носіями мови;
виправлення вітаються. Нова мова — це новий розділ у `EvtList.lng`,
названий за мовним файлом Total Commander (`WCMD_POL.LNG` → `[pol]`).

## Збирання

MinGW-w64, див. `build.bat`. Вихідні файли: `evtlist.cpp` (WFX), `evtsource.cpp` (доступ до журналів),
`settings.cpp` (ini і діалог), `lang.cpp` (переклади).
